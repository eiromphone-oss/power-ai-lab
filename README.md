プロジェクト名

発電設備保全意思決定支援AI

30日試作品の目的

複数の発電所から提出された修繕候補案件を、安定供給、安全・環境、設備状態、修繕効果および費用の観点から横断的に比較し、限られた予算内で優先すべき案件と、その判断根拠を提示する。

AIの役割

AIが最終決定するのではなく、評価結果の説明、不足情報の指摘、類似案件の検索および検討資料の作成を支援する。最終判断は人間が行う。

30日後の完成状態
20件程度の案件をCSVまたはExcelから読み込める
各案件のリスクと修繕効果を計算できる
修繕優先順位を表示できる
予算上限内の推奨案件を表示できる
順位の理由と不足情報を文章で表示できる
AIは最終決定を行わないこと
